Introducing My Diary Pro

We're excited to launch My Diary Pro — a premium tier that unlocks more power for your diary.

Pro features:

  • Unlimited entries (free plan: 10)
  • 50 items in trash (free: 2)
  • Unlimited custom tags (free: 3)
  • Edit selected text and source before saving
  • Export to JSON & Markdown
  • Dark mode
  • Folders & categories

v2.1.0

January 2026

New

  • Entries count — The Entries tab now shows how many items you have saved, similar to the Trash count.
  • Edit selected text and source (Pro) — Pro users can edit the selected text and source before saving. Click Edit next to either field to tweak your snippet or change the display text and link. Free users see an "Edit with Pro" option.
  • Show or hide custom tags — In the Add to My Diary window, you can collapse the custom tags section to keep the view clean. Your choice is remembered.

Improved

  • Entries count badge uses a subtle slate color so it's distinct from the red trash badge.
  • Custom tags section uses the same layout and spacing as the default tags.
  • Trash limit warning now offers "Upgrade to Pro" and "Delete anyway" options when you're about to exceed the free plan limit.

v1.1.0

January 2026

New

  • Copy button — Tap the copy icon on any entry to copy its text (and your note, if you added one) so you can paste it elsewhere. A checkmark confirms it’s copied.
  • Scrollable long entries — For longer saved text, you can scroll inside the entry instead of it taking up the whole list.

Improved

  • Tags now appear in a clearer format (e.g. Text, Link, Quote) everywhere.
  • Each entry shows both “how long ago” and the exact date and time (e.g. 5m ago · Jan 26, 2:30 PM).
  • Hint text in search and comment boxes is lighter and easier on the eyes.
  • When you add an entry on a dark website, the “Add tag” and “Comment” boxes stay light with dark text so they’re easy to read.

Fixed

  • On dark-themed sites, the tag and comment fields when adding an entry no longer turn dark and hide the text.

v1.0.0

January 2026

What’s included

  • Select any text on a page, right‑click, and choose Add to My Diary to save it.
  • When adding, you see a small window with your selection, optional tags (Text, Link, Quote, etc.), and a box for your own notes.
  • Search your diary, filter by tag or favourites, and star entries you care about most.
  • Deleted entries go to Trash (last 5). You can restore them or remove them permanently.
  • Copy, favourite, and delete buttons on each entry; add or edit a note anytime.
  • Simple, clean design. Everything stays on your device — we don’t collect or store your data.
