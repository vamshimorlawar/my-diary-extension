My Diary

Save text snippets from any webpage to your personal diary

Features

  • Right-click any selected text to save it instantly
  • Add tags to organize your entries
  • Create custom tags for better organization
  • Add personal comments and notes
  • Mark entries as favourites
  • Search and filter your saved content
  • Trash with restore functionality
  • Clean, minimal interface

Installation

Install from the Chrome Web Store or load unpacked from GitHub.

Privacy

All your data is stored locally in your browser. We don't collect, transmit, or store any of your information on external servers. Read our full Privacy Policy.
