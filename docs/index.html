Features

  • Add tags to organize your entries
  • Create custom tags for better organization
  • Add personal comments and notes
  • Mark entries as favourites
  • Search and filter your saved content
  • Trash with restore functionality

How it works

Select text on any page, right-click, and choose Add to My Diary. Your snippets appear in the extension popup with tags, search, and favourites.
